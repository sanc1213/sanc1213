# Profile Hub — Ultimate User Profile & Account Hub

React + TypeScript + Tailwind CSS + Framer Motion + Lucide.

```bash
cd profile-hub
npm install
npm run dev      # http://localhost:5173
npm run build    # type-check + production build
```

Features: cover/avatar editing, status dot, share + public-mode preview, Overview bento (bio/skills editing, metrics, heatmap, filterable feed, pinned), validated account form, password drawer, 2FA with QR setup, session revocation, notification matrix, Light/Dark/System + accent themes (persisted), collapsible billing with usage, invoices download. Keyboard-navigable tabs (arrow keys), focus-trapped dialogs, ARIA roles, skeleton loaders, toasts.
